# PassimPay для PrestaShop — 2.0.1

1. Сохраните резервную копию файлов модуля и базы магазина.
2. Распакуйте `passimpay_prestashop.zip`: каталог `passimpay` должен находиться в `<магазин>/modules/passimpay/`. При обновлении замените файлы существующего модуля. Не создавайте вложенную папку `passimpay/passimpay` и не удаляйте модуль: удаление очищает настройки.
3. При первой установке установите модуль через Module Manager. Откройте PassimPay → Configure, укажите Platform ID и Secret Key своего проекта и выберите способы оплаты. Для карт включите Cards / Bank transfer в проекте PassimPay.
4. Скопируйте Webhook URL из настроек модуля в Notification URL проекта. Для магазина в корне домена: `https://shop.example/modules/passimpay/webhook.php`.
5. В проекте PassimPay задайте страницы успешного и неуспешного возврата покупателя. Они не заменяют Notification URL.
6. Очистите кеш PrestaShop и выполните контрольную покупку: проверьте сумму, валюту и автоматическое обновление статуса заказа.

Модуль использует API v2 автоматически. Сумма и валюта берутся из заказа; валюта должна поддерживаться PassimPay. Нужны PHP cURL и исходящий HTTPS к `https://api.passimpay.io` с действующим хранилищем корневых сертификатов.

Статус оплаты определяется серверной проверкой платежа. Адрес уведомлений должен принимать POST JSON и заголовок `x-signature` без перенаправлений и проверок браузера. Актуальные IP-адреса отправителей для настройки сервера получите у [поддержки PassimPay](https://passimpay.io/en/contacts); требования описаны в [документации уведомлений](https://passimpay.gitbook.io/passimpay-api/webhook).

Platform ID и API Key доступны в настройках проекта в [кабинете PassimPay](https://account.passimpay.io/).
